# ESP32-C6 Weather Display

Weather forecast app for the **Waveshare ESP32-C6-LCD-1.47** development board
(ESP32-C6, 1.47" 172×320 ST7789 display).

The device connects to WiFi, fetches the Open-Meteo forecast for your location
(today and tomorrow), and renders it on the display with color weather icons,
an auto-refreshing forecast, and an RGB LED status indicator.

## Features

- Today's and tomorrow's forecast (conditions, current temp, high/low)
- Color weather icons (sun, partly cloudy, cloud, rain, snow, thunder, fog)
- Auto-refresh every 30 minutes
- RGB LED status: blue = connecting, yellow = fetching, green = ok, red = error
- Screen power management:
  - Backlight turns off after 5 minutes idle (`SCREEN_IDLE_TIMEOUT_S`)
  - The **BOOT button** toggles the screen on/off; waking re-fetches the forecast
  - Ready for an external motion/touch sensor: call `screen_request_wake()`,
    `screen_request_sleep()` or `screen_request_toggle()` from any context

## Hardware

- Board: Waveshare ESP32-C6-LCD-1.47 (`ESP32-C6FH8`, 8 MB flash)
- Display: 1.47" ST7789, 172×320, SPI, RGB565 (little-endian), inverted colors
- RGB LED: WS2812 on GPIO8 (RMT)

### Pin map

| Function   | GPIO |
|------------|------|
| LCD MOSI   | 6    |
| LCD SCLK   | 7    |
| LCD CS     | 14   |
| LCD DC     | 15   |
| LCD RST    | 21   |
| Backlight  | 22   |
| RGB LED    | 8    |
| BOOT button| 9    |

## Requirements

- Docker (the build runs inside the official `espressif/idf:v5.5.5` image, so no
  local ESP-IDF install is needed)
- USB cable to the board (appears as `/dev/ttyACM0` via USB Serial/JTAG)

## Build & flash

```sh
./build.sh build    # compile
./build.sh flash    # flash to the board (PORT=/dev/ttyACM0)
```

## Configuration

Edit `main/board_config.h`:

- `WIFI_SSID` / `WIFI_PASS` — your 2.4 GHz network (the C6 does not support 5 GHz)
- `WEATHER_LAT` / `WEATHER_LON` — forecast location coordinates
- `WEATHER_LOC` — label shown in the header

> Note: WiFi credentials are compiled into the firmware and stored in this repo.

## Project layout

```
main/
  main.c          app orchestration (wifi, refresh loop, rendering)
  display.c/h     ST7789 driver + framebuffer + text/icon drawing
  screen.c/h      backlight power management + BOOT button / sensor hooks
  weather.c/h     WiFi + Open-Meteo HTTP client + JSON parsing
  led.c/h         WS2812 RGB LED
  board_config.h  pins, WiFi, location
  generated/      fonts + icons (generated by tools/gen_assets.py)
components/led_strip/   vendored WS2812 driver (espressif/idf-extra-components)
tools/gen_assets.py     regenerates fonts/icons with PIL + DejaVu Sans Bold
```

## Notes

- The 172×320 panel is a strip of the ST7789's 240×320 memory: column offset 34,
  row offset 0. Orientation uses MADCTL `0x40` (MX) for this panel revision.
- Regenerating assets: `python3 tools/gen_assets.py` (requires Pillow + a DejaVu
  font, only needed if you change the icons or fonts).
